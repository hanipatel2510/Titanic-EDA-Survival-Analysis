# 🚢 Titanic Survival Analysis

## 📌 Project Overview

**Titanic Survival Analysis** is a Python-based Exploratory Data Analysis (EDA) project. It analyzes passenger information from the Titanic dataset to identify patterns associated with survival.

The project focuses on **gender, passenger class, age, fare, and family size**, using tables, statistics, and visualizations to communicate the findings.

## 🎯 Objectives

- Understand the Titanic dataset
- Inspect data structure and statistics
- Identify and handle missing values
- Check and remove duplicate records
- Analyze overall survival and survival rate
- Compare survival by gender and passenger class
- Study age, fare, family size, and age groups
- Perform combined-factor analysis
- Analyze correlations between numerical variables
- Present clear findings and conclusions

## 🛠️ Technologies Used

- **Python**
- **Pandas** — data manipulation and analysis
- **NumPy** — numerical operations
- **Matplotlib** — data visualization
- **Seaborn** — statistical visualization
- **Jupyter Notebook** — interactive analysis

## 💡 Key Insights

The analysis shows clear differences in survival patterns between passenger groups. Female passengers had a substantially higher survival rate than male passengers, while first-class passengers generally had better survival outcomes than passengers in lower classes.

Age, fare, and family size also showed useful patterns. Fare differences were closely connected to passenger class and provided additional context for the survival analysis.

The findings represent relationships observed in the dataset and should not be interpreted as proof of direct causation.
